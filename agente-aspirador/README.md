# Agente aspirador de pó (AIMA): testes e análise PEAS

- `RELATORIO.md`: relatório com a análise PEAS dos resultados.
- `experimentos.py`: bateria de testes (código próprio). Rode com `python3 experimentos.py`.
- `aima/`: código original do AIMA, sem modificação (ver `PROVENIENCIA.md`).
- `resultados/`: tabelas em CSV e a saída completa da execução.

Requisitos: Python 3.12, `numpy`, `ipython`.
